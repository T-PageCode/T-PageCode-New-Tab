# T-PageCode-New-Tab
T-PageCode新标签页扩展，搜索引擎为GitHub Search
## 使用说明
1.首先点击GitHub的Code -> Download ZIP
2.解压下载的ZIP,打开Chrome浏览器
3.点击右上角三点菜单 -> 扩展程序 -> 管理扩展程序
4.找到右上角的开发者模式,点击开启
5.这时候就有三个选项,点击加载未打包的扩展程序
6.弹出文件夹选择框时,选择您刚才解压的源码文件夹
7.新建一个标签页,如果提示修改了默认标签页,同意即可
8.您可能会看到底部的个性化Chrome和其他元素,右键隐藏即可
9.如果想恢复原来的标签页,卸载扩展就可以
## CRX说明
1.首先到GitHub Releases里下载CRX文件
2.打开Chrome浏览器
3.点击右上角三点菜单 -> 扩展程序 -> 管理扩展程序
4.打开文件资源管理器,切换到您下载CRX的目录
5.拖拽CRX文件到Chrome,然后安装
6.新建一个标签页,如果提示修改了默认标签页,同意即可
7.您可能会看到底部的个性化Chrome和其他元素,右键隐藏即可
8.如果想恢复原来的标签页,卸载扩展就可以
